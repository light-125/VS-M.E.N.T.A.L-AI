# 🧠 VS M.E.N.T.A.L AI — 究極の心理戦ロシアンルーレット

> **「その引き金は論理か、それとも狂気か。」**

あなたの行動パターンをリアルタイムに学習・分析する心理解析AI「M.E.N.T.A.L AI」と対峙する、極限の10連発変則ロシアンルーレットゲーム。
3つのアイテム、突発イベント、プレイヤーをメタ解析するAIが絡み合い、生存率10%（残り1発）の極限状態まで勝負が継続する緊張感あふれるWebベースのデスゲームです。

---

## 1. ゲーム概要と基本ルール

10個のチャンバー（弾を込める穴）を持つリボルバーを使用し、プレイヤーとAIが交互に引き金を引く、または降りる（ドロップ）を選択します。

- **初期状態**: プール金1,000円、シリンダー残り10個、実弾1発装填（生存率90.0%）。
- **確率の自動変動**: 1/10 ➔ 1/9 ➔ 1/8 ➔ ... ➔ 1/2（50%） ➔ 1/1（100%）。
- **極限デッドライン**: 残り穴数が1個（生存率10.0%に到達し、次の1発が実弾確定の状態）になった時点でゲームが自動終了。プール金が折半され、互いの銀行口座に分配されます。

---

## 2. ゲームの核を成す3つの流れ（ギミック）

### 1. 戦局を覆す「3つの特殊兵装（アイテム）」
- 👁️ **透視 (Scan)**: 次の1発が「実弾」か「空」かを解析しログに表示。
- 🛠️ **不発工作 (Jam)**: 自身のターンをスキップし、リボルバーをAIへ強制移行。
- 💬 **脅迫 (Bluff)**: AIの論理プロセッサを書き換え、AIの逃亡確率を飛躍的に高めます。

### 2. 突発的な「ラウンドイベント」
- **【通常モード】** (発生率 60%): 通常の制限時間10秒、生存時プール金2倍。
- 🔥 **【高レートモード】** (発生率 20%): 生存時の賞金プールが**3倍**に爆増。
- 🚨 **【極限モード】** (発生率 20%): 制限時間が**4秒**に劇的短縮。時間切れは強制発砲。

---

## 3. AIアルゴリズムの内部設計

本ゲームの対戦相手である「M.E.N.T.A.L AI」は、プレイヤーの行動履歴を動的にメタ解析するアルゴリズムを搭載しています。

1. **リスク傾向の算出**: `pr = ts / tt` （生き残った割合が高い＝豪胆、低い＝チキン）。
2. **AIのドロップ閾値（th）の決定**: `th = 0.35 + ((1 - pr) * 0.3)`
   - 慎重なプレイヤー（`pr`が低い）に対しては、AIは強気に引き金を弾き続けます。
   - 大胆なプレイヤー（`pr`が高い）に対しては、AIは早期にドロップして利益を守ります。

---

## 4. ユニバーサルデザイン（UD）への配慮

- **厳選された3つのUDフォント**: `Space Mono`（ブレない等幅英数）、`LINE Seed JP`（明瞭な日本語ゴシック）、`Noto Color Emoji`（ブラウザに依存しないビビッドな表現）。
- **高コントラスト配色**: 純黒背景に対し、緑（安全）、黄（警告）、赤（危険）を厳格に割り当て。

---

## 5. 開発秘話と技術的限界（重要）

### 💾 LocalStorage実装への挑戦、そして敗北
当初の設計思想では、ブラウザの `LocalStorage` を活用してプレイヤーの累計戦績を永続的に保存し、動的に称号が変化する「永続的セーブ機能」を構築しようと本気で試みました。

しかし、**「Object.seal によるスコープ固定化」「jQuery 3.7.1のイベント伝播の競合」「非同期タイマーとDOM書き換えのデッドロック」**というフロントエンド開発における最凶の壁がトリプルコンボで立ちはだかり、デバッグの泥沼化の末、**「やろうと思ったけど無理だった」**という結論に至りました。

結果として、ゲームの安定性とエディタ（VS Code）のクラッシュ防止を最優先するため、LocalStorage機能は華麗にオミット（無かったことに）されました。このゲームは、**「その場限りの刹那的な命の削り合い」を楽しむ純粋なアーケードスタイル**として究極の完成度を誇っています。
